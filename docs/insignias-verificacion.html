Insignias de verificación

Azul = Estrella Creadora · Morada = Plan de pago. Son dos insignias distintas y nunca deben confundirse.

Verificación

Estrella Creadora

  • Color: celeste / azul brillante.
  • Forma: sello circular con check y checklist blanca.
  • Se obtiene: por verificación del equipo (mérito), no por pago.
  • ID: verified_creator_star
  • No usar para: indicar suscripción o plan premium.
Plan de pago

Plan comprado

  • Color: morado con degradado rosa.
  • Forma: escudo con portapapeles y checklist blanca.
  • Se obtiene: al comprar/activar el plan.
  • Se pierde: si el plan vence o se cancela.
  • ID: verified_plan_paid
  • No usar para: mérito, identidad o Estrella Creadora.

Instrucción para ChatGPT y GitHub

En este proyecto existen dos insignias de verificación. La azul (sello circular con check y checklist) significa Estrella Creadora y se obtiene por verificación del equipo, no por pago. La morada con rosa (escudo con portapapeles) significa que el usuario compró el plan de pago. No las mezcles, no las intercambies y no uses una para representar lo que corresponde a la otra. Al generar código, documentación, issues o pull requests, respeta esta distinción y usa los identificadores verified_creator_star y verified_plan_paid.
